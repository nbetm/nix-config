# Nord Deep

[Nord], but deeper: darker backgrounds for clearer layering, plus two derived sub-palettes for row and pill backgrounds.
Read [palette.md](palette.md) for the spec and the design language.

## Ports

| App | File |
| ------- | ---------------------------------------------------------- |
| bat | `configs/bat/dot-config/bat/themes/nord-deep.tmTheme` |
| btop | `configs/btop/dot-config/btop/themes/nord-deep.theme` |
| ghostty | `configs/ghostty/dot-config/ghostty/themes/nord-deep` |
| helix | `configs/helix/dot-config/helix/themes/nord-deep.toml` |
| kitty | `configs/kitty/dot-config/kitty/themes/nord-deep.conf` |
| plasma | `configs/plasma/dot-local/share/color-schemes/NordDeep.colors` |
| tmux | `configs/tmux/dot-config/tmux/themes/nord-deep.conf` |
| yazi | `configs/yazi/dot-config/yazi/flavors/nord-deep.yazi` |

Ports sit next to the app config they belong to, which keeps the `dot-` stow layout working and `configs/<app>/` a complete picture of that app.

[nord]: https://www.nordtheme.com/
